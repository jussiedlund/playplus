# Play+ website

Double-click **Start Play+ Site.command** in Finder for the quickest local preview. It installs dependencies when needed, starts Astro, and opens the site in your browser.

## Terminal setup

```sh
npm install
npm run dev
```

Before production deployment, add the licensed font files described in `public/fonts/README.md`, replace the labeled book/portrait placeholders, confirm retailer URLs and endorsement copy, and connect the newsletter form.

See `CONTENT.md` for the copy and content map.
